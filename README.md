# SDP — BOPTEST default simulator setup

A reproducible **local setup** for the official [BOPTEST](https://github.com/ibpsa/project1-boptest) **v0.9.0** `bestest_air` single-zone building simulator, plus a small Python research collector. Prepared for sharing the current senior-design-project simulator workflow with the course advisor and team.

**This is not a modified building model or a browser-hosted simulator.** The official BOPTEST source is downloaded and checksum-verified during setup; it is *not* included in this repository. The building still uses its packaged Denver typical meteorological year and original occupancy schedule. Our files provide Windows/Docker setup, a local verification test, and Python data collection.

**Start here:** [START_HERE.txt](START_HERE.txt)  
**Detailed experiment instructions:** [research/README.md](research/README.md)  
**Supported versus pending changes:** [research/CAPABILITIES.md](research/CAPABILITIES.md)

## Windows quick start

1. On a Windows x64 PC, install [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/) with Linux/WSL2 containers and install Python **3.12**.
2. Download this repository with **Code → Download ZIP** (or clone it), then extract it to a writable folder. Do not run from inside a ZIP.
3. With Docker Desktop running, double-click **`SETUP_FIRST.cmd`**. Internet access, disk space and time are required; this downloads official BOPTEST v0.9.0 and builds its containers.
4. Double-click **`VERIFY_INSTALL.cmd`**. A successful live check initializes a *disposable* building, advances it three times by five minutes, checks measurements and cleans up.
5. Double-click **`GENERATE_DATASET.cmd`** to configure a **new** short research run, and read [research/README.md](research/README.md) before using any data scientifically.
6. Double-click **`STOP_BOPTEST.cmd`** to stop only this package's Docker stack after all research/verification work finishes.

**There is no dashboard in this repository.** To access the running simulator programmatically, use the local API at `http://127.0.0.1:80` after setup. This address works **only on the computer running BOPTEST**, not remotely from an advisor's browser.

## Scope and research integrity

This package is **not** the original complete D2 campaign collector; the independent simpler collector is `SDP_TEAM_RESEARCH_1.0.0`. No new dataset or experiment was created during GitHub packaging. Existing frozen experiment evidence is not modified or included. To combine datasets across computers, coordinate scenario partitions and audit full successful run folders; see [research/README.md](research/README.md).

The previous home-built simulator used a variable labeled **“AC.”** In this BOPTEST setup, the forecasting demand target is **cooling equipment electrical power plus fan electrical power** (kW). These are not guaranteed to be the same quantity. Temperature and power are generated by the simulator, not measured from a real building.
